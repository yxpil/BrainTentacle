好的，来一个简单点的 ER 图（以「用户-订单-商品」为例）：

```mermaid
erDiagram
    USER ||--o{ ORDER : "下单"
    ORDER ||--|{ ORDER_ITEM : "包含"
    PRODUCT ||--o{ ORDER_ITEM : "被购买"

    USER {
        int id PK
        string name
        string phone
    }
    ORDER {
        int id PK
        int user_id FK
        date created_at
    }
    PRODUCT {
        int id PK
        string title
        decimal price
    }
    ORDER_ITEM {
        int id PK
        int order_id FK
        int product_id FK
        int qty
    }
```
含义说明：
- **USER 1 : N ORDER** — 一个用户可以有多个订单
- **ORDER 1 : N ORDER_ITEM** — 一个订单包含多条明细
- **PRODUCT 1 : N ORDER_ITEM** — 一个商品可出现在多条明细中
