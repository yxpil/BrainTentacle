隐私政策

触手怪 BIT 桌面应用（含通过 Microsoft Store 分发的版本）。一句话概括：不收集、不上传、不遥测。

BIT 仅为连接 AI 服务的通用客户端工具，不提供、不托管、不转接任何 AI 模型服务；模型服务由用户自行选择并配置的第三方提供。下载、安装或使用本软件，即表示你已阅读、理解并同意本页全部条款。

1. 我们收集什么数据

什么都不收集。BIT 没有账号系统、没有统计埋点、没有崩溃上报、没有广告 SDK。我们不知道你是谁、不知道你装没装 BIT、也看不到你的任何对话。

2. 数据存在哪里

你的全部数据——配置、对话记录、记忆、技能脚本、审计日志——只保存在你自己的电脑上（用户数据目录）。卸载应用即随之删除。BIT 官方服务器（osbt.space）不存储、不中转任何用户数据。

3. 网络请求去向

  • AI 服务商：你的对话内容只会发送到你自己配置并填入密钥的 AI 服务商（OpenAI / Claude / Gemini 或任意兼容端点）。BIT 不经过任何自有服务器转发。你与所选服务商之间适用其隐私政策。
  • MCP 服务器：由你自行添加的第三方 MCP 服务，数据流动范围由你决定。
  • 版本检查：应用启动或手动检查更新时，会请求版本清单文件（托管于 GitHub Pages、osbt.space 与 GitHub API）。请求只包含标准 HTTP 元信息（如 IP 地址，由 CDN 常规处理），不包含任何设备标识或用户数据。

4. 远程访问功能

BIT 提供可选的局域网/远程访问。该功能默认关闭；开启后仅限你自行设置的访问密码与 Client Key 认证，数据端到端由你掌控。

5. Microsoft Store

通过 Microsoft Store 获取的版本同样不含任何遥测。商店的分发、许可与支付流程由微软提供，适用微软隐私声明。

Privacy Policy

For the BIT desktop app, including builds distributed via Microsoft Store. In one line: no collection, no upload, no telemetry.

BIT is a general-purpose client tool for connecting to AI services. We do not provide, host, or relay any AI model services; model services are supplied by third parties that you choose and configure yourself. By downloading, installing, or using this software, you acknowledge that you have read, understood, and agreed to all terms on this page.

1. What we collect

Nothing. BIT has no accounts, no analytics, no crash reporting, and no advertising SDKs. We don't know who you are, whether you installed BIT, or anything about your conversations.

2. Where your data lives

All of your data — settings, conversations, memories, skill scripts, audit logs — stays on your own computer (user data directory) and is removed when you uninstall. osbt.space servers store and relay no user data.

3. Network requests

  • AI providers: your prompts are sent only to the AI provider you configure with your own API key (OpenAI / Claude / Gemini or any compatible endpoint). BIT never relays them through our servers. Your chosen provider's privacy policy applies between you and them.
  • MCP servers: third-party MCP servers you add yourself; you decide what data flows to them.
  • Update checks: the app fetches a version manifest (hosted on GitHub Pages, osbt.space and the GitHub API) when checking for updates. Requests contain only standard HTTP metadata (such as your IP, processed routinely by CDNs) — no device identifiers, no user data.

4. Remote access

Optional LAN/remote access is off by default. When enabled, it is protected by your own access password and Client Key. You remain in full control.

5. Microsoft Store

The Microsoft Store build contains no telemetry either. Store distribution, licensing and payment are handled by Microsoft under the Microsoft Privacy Statement.
