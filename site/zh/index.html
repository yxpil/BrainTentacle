AI 的触手，
长在你的桌面上。

触手怪 BIT 是一个桌面 Agent 中枢：Electron 壳 + Rust 核心（bit-core）+ React 界面。 配置任意模型即可流式对话，让它调用本机工具、现写脚本、把结论沉淀成记忆与技能。 密钥对 AI 脱敏，数据不出本机，每一次调用都留下审计记录。

它把 AI 从聊天框里放出来

不只是问答。工具在本机执行、脚本由 AI 自己写、结论跨会话留在你机器上——下面这些能力全部离线可用，不需要任何账号。

工具中枢

注册、启停、调用工具；自动探测本机解释器（Python / Node / PowerShell / Perl / Julia…）。AI 只要写一段能从 stdin 读参、向 stdout 输出的脚本，它就变成一件工具，热更新，每项带成功率与平均耗时。

三层扩展

一个 plugin.json 的本地插件、任意标准 MCP 服务器、或者直接托管你自己的常驻程序。三层能力最终都汇进同一个工具注册中心，AI 一视同仁地调用。

记忆与技能

AI 用内置的 add_memory 与 skill 自主沉淀：这次踩的坑、这套项目的规矩、这段流程的做法，下次直接复用，不需要你手动整理。

子智能体

Autopilot 打开后，待办会被自动派给子代理并行推进；计划目标与任务进度在「记忆」页随时可查、可删。

长任务不中断

关窗即驻留托盘，右键任务面板看会话回合、后台命令、子代理与活跃目标；长命令自动转后台，执行中切走不中断，可开启「阻止系统休眠」。

远程与网关

开启远程访问后暴露完整 HTTP API（默认 0.0.0.0:8600），并提供 OpenAI 兼容端点 /v1/chat/completions，把桌面上的模型与工具变成局域网里的网关。

标准 MCP 双端

既是 MCP 客户端（Streamable HTTP 或 stdio 导入外部工具），也是标准 MCP 服务端：POST /mcp，协议版本自动协商，Claude Desktop / MCP Inspector 可直接接入。

终端模式

装好后在任意终端输入 bit 直接进 TUI：无窗口、无单实例约束、不监听端口，适合 SSH 与无桌面环境。

三层扩展，从轻到重

本地插件最省事，MCP 接现成生态，WorkWith 直接托管你自己的程序。三者最终都把能力汇进同一个工具注册中心，AI 一视同仁地调用。

01

本地插件：一个文件夹，一份 plugin.json

把插件包丢进数据目录的 toolhomes/plugins/，点一次「重扫插件」，工具、提示词、技能、记忆与定时任务同时生效。也可以在里面直接声明常驻服务、独立页面和对话页图标入口。

02

MCP 扩展：粘贴一份 mcpServers 配置

兼容 Cursor 与 Claude Desktop 的配置格式，支持 command + args + env；也能扫描端口范围，自动发现局域网里跑着的 MCP 服务。

{ "mcpServers": { "files": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem"] } } }
03

WorkWith：把常驻程序交给它托管

在「服务」页填一下程序路径，添加即完成——自动拉起进程、自动扫描端口、自动接入 MCP。工具即插即用，端口、日志与退出都由宿主统一管理。

插件生态：一个文件夹，就是一项新能力

不用打包、不用编译、不用碰宿主代码。在插件目录里放一个 plugin.json，工具、提示词、技能、记忆、定时任务、常驻服务和独立页面就同时交到 AI 手里；改完点一次「重扫插件」即刻生效。插件是本地声明式文件——没下载就不会被执行。

工具tools[]
声明一件 AI 能调用的工具：参数用 JSON Schema 描述，脚本从 stdin 读参数、把结果打到 stdout。跑本机解释器（Python / Node / PowerShell / Perl / Julia…），或走内置 Rhai 沙盒。每件工具都带成功率与平均耗时。
提示词prompts[]
启用即追加到系统提示词。把「这个项目用 pnpm 不用 npm」「回答先给结论」这类规矩写进插件，换台机器装同一个插件，AI 的做事方式跟着走。
技能skills[]
注入可复用流程（名字 + 摘要），与 AI 自己提炼的技能同构。适合把一套排查步骤、一类文档的写法固化成插件的一部分。
记忆memories[]
作为长期事实注入：本机默认工作目录、内网域名、团队口径，装好就在，不必每次重新交代。
定时任务jobs[]
every 30m / daily 09:00 这类频率，脚本定期跑；结果可以注入指定会话让 AI 接着处理，也可以只记审计日志。
常驻服务services[]
最多 16 条：插件自带一个进程，端口由宿主分配（写 0 即自动，经 BIT_PLUGIN_PORT 下发），日志与退出统一托管；mcp_mode 选 http 时端口就绪后自动接成 MCP 服务器，选 stdio 则进程本身即 MCP。
页面pages[] · status_page
在左栏注册独立页面（沙箱 iframe，静态 src 或动态 url 二选一），还能给插件详情配一块实时状态面板——看板、指标、健康检查都放得下。
对话页入口chat_icons[] · takeover[]
最多 4 个图标入口：点了跳本插件页面，或把一段提示词填进输入框。要更彻底就声明接管内置按钮（语音 / 预览 / 附件 / 计划 / 模板 / 网页 / 后台任务），用插件自己的入口顶上；设置入口永不参与接管，随时可一键恢复内置。
权限申报permissions[] · bridge
每一项能力都要明示申报，没申报的调用直接被拒。设置中心把权限逐项列出、逐项开关，exec（执行命令）与 write（改任意文件）标为高风险。要对外开接口（自带服务器 / 页面 / 设置页）必须写 bridge，令牌每次启动现发，不随插件包分发。

三步接入

01

找到插件目录

固定在数据目录下的 toolhomes/plugins/。装了 BIT 的话，「工具」页 →「本地插件」区块会直接显示完整路径，点一下就能复制。

Windows%APPDATA%\com.bit.hub\toolhomes\plugins\
macOS~/Library/Application Support/com.bit.hub/toolhomes/plugins/
Linux${XDG_DATA_HOME:-~/.local/share}/com.bit.hub/toolhomes/plugins/
02

放一个文件夹进去

目录名就是插件 id，层级必须是 plugins/<插件名>/plugin.json，不能多层嵌套。现成的插件包解压到这里即可；自己写的就在目录里放一个 plugin.json——它是唯一的清单文件，脚本、页面、设置都写在同目录、按相对路径引用。

03

点「重扫插件」

工具立刻出现在工具列表，prompts 与 memories 下次对话生效。每个插件有独立启停开关，重扫不会丢掉你的选择；扫不动的插件会被跳过并列出具体原因，不会静默消失。

一份能跑通的最小清单（工具 + 提示词 + 技能 + 记忆 + 定时任务）：

{
  "name": "我的插件",
  "version": "0.1.0",
  "description": "一句话说明这个插件干什么",
  "tools": [{
    "name": "disk_usage",
    "description": "查看指定目录的磁盘占用",
    "parameters": {
      "type": "object",
      "properties": { "path": { "type": "string", "description": "目录路径" } },
      "required": ["path"]
    },
    "kind": "interpreter",
    "runtime": "py",
    "file": "disk_usage.py"
  }],
  "prompts": ["回答时优先使用中文。"],
  "skills": [{ "name": "磁盘排查", "summary": "先用 disk_usage 看占用，再逐层往下钻" }],
  "memories": ["本机默认工作目录是 D:/work"],
  "jobs": [{
    "name": "日报",
    "schedule": "daily 09:00",
    "runtime": "py",
    "file": "daily.py"
  }]
}

工具脚本的通讯约定和手写工具完全一致——从 stdin 读参数 JSON，把结果打到 stdout：

import json, sys, shutil

params = json.loads(sys.stdin.read() or "{}")
total, used, free = shutil.disk_usage(params.get("path", "."))
print(json.dumps({"total": total, "used": used, "free": free}, ensure_ascii=False))

密钥不进模型，数据不出本机

发给 AI 之前先脱敏，危险工具执行之前先二审，所有调用事后可查。没有账号系统，也没有任何遥测。

虚线＝工具调用与本机还原，原文全程不经过模型上下文

HiddenCode 脱敏

密钥、手机号、邮箱、用户名在发给 AI 前换成占位符或你设定的别名（小明 → 李四）；工具执行时自动还原。支持内置类型掩码、精确值、自定义正则与粘贴扫描。

L2 PASS 二级审核

工具执行前先由另一个模型判 Allow / Deny，可覆盖自动放行工具；审核模型不可达时回退人工审批，不打断正常使用。

审计日志

每次工具调用与关键操作都留痕，可按主体 / 动作 / 目标过滤，事后复盘是谁在什么时候碰了什么。

数据本地化

会话、记忆、技能、配置全部保存在本机数据目录（Windows %APPDATA%\com.bit.hub，macOS ~/Library/Application Support/com.bit.hub），卸载即删除。

文档与常见问题

完整安装、插件规范、API 与 MCP 细节都在仓库里；下面是上手时最容易卡住的几处。

仓库说明 Wiki · 快速上手 English README
macOS 提示「已损坏，无法打开」

触手怪目前是 ad-hoc 签名（没有付费开发者证书），浏览器下载会带上隔离标记，macOS 会把它误报成「已损坏」。应用本身的签名是完整的，去掉隔离标记即可：

xattr -cr /Applications/BIT.app

也可以在 系统设置 → 隐私与安全性 中点「仍要打开」。

Windows 提示 SmartScreen 已阻止

安装包未做代码签名，首次运行点「更多信息 → 仍要运行」即可。便携版同理。

第一次打开要配什么

进入「AI 设置」→「添加提供方」→ 选协议（OpenAI / Gemini / Claude）、填 Base URL 与 API Key、填模型名（可点「从 API 获取」一键拉取模型列表）→ 点该条目上的播放按钮激活。同一时刻只有一个提供方生效，其余自动暂停。

怎么让 Claude Desktop 用上我的工具

开启「远程访问」后，触手怪就是一个标准 MCP 服务端：端点 POST /mcp，协议版本 2024-11-05 / 2025-03-26 / 2025-06-18 自动协商，支持 Mcp-Session-Id 会话与 tools/list / tools/call。把 MCP 客户端指向 http://主机:8600/mcp 即可，认证与远程 API 同一套。

数据存在哪，怎么彻底卸载

Windows %APPDATA%\com.bit.hub，macOS ~/Library/Application Support/com.bit.hub，Linux ${XDG_DATA_HOME:-~/.local/share}/com.bit.hub。删掉这个目录就是彻底清空；设了 BIT_DATA_DIR 环境变量时以它为准。

企业内网要走代理怎么办

「设置 → AI 设置 → 网络代理」三档：跟随系统 / 强制直连 / 自定义代理。自定义支持 http / https / socks5，设一次三处同口径生效——模型请求与更新下载、curl / git / npm 等子进程的环境变量、内嵌浏览器会话。界面上地址与密码一律打码。

为什么永久免费，有没有遥测

Apache-2.0 开源，所有功能对个人与商业用户免费：没有内购、没有订阅、没有功能锁、没有遥测，也可以自行编译。没有账号系统，软件不需要联网也能装好；只有在检查更新时才会请求版本清单。
